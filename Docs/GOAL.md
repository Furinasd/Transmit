# Project Goal

Build a third-person combat-puzzle prototype around "Transfer".

## Player Experience

Players understand one transferable rule, then progressively exploit it across:

- Player
- Enemy
- Environment

## Success Criteria

- Core mechanic is readable within approximately 30 seconds.
- Five-level paper progression exists.
- Three levels are playable.
- Combat and puzzle use the same underlying system.
- The project remains compatible across supported UE 5.8 target platforms.

## Non-Goals

- Deep skill tree
- Content-heavy enemy roster
- Art-asset-driven spectacle
- Large narrative scope
